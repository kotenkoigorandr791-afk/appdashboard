# Public API

**Location**: `/public-api/`

## Overview

The public API provides RESTful endpoints for all AppDashboard functionality, including the service shell, all 13 apps, configuration, authentication, and system management. It exposes these endpoints over HTTPS-only via Bearer token + `X-Device-Id` headers (unless configured with HTTP support locally).

## Base URL

```
https://YOUR_HOST/public-api/v1
```

## Authentication

### Method 1: Bearer Token + Device ID

Required headers:

```
Authorization: Bearer <64-character hex token>
X-Device-Id: <32-128 character hex device ID>
```

- **Bearer token**: Generated by `POST /public-api/auth/token`
- **Device ID**: Random hex string (format: 32-128 characters) used for token binding

### Method 2: Session-Cookie (for UI-in-browser)

When accessing API from the UI, session cookies are used implicitly.

## Authorization Levels

| Endpoints | Minimum Role |
|-----------|--------------|
| Admin endpoints | Admin (2) |
| App endpoints | Guest is denied; Manager/Admin allowed |
| Shell endpoints (service management) | Admin only |
| Integrations endpoints | Admin only |
| Auth endpoints | Open |

## Rate Limiting

- **Failed login attempts**: IP-based lockout (exponential backoff)
- **Attempts**: 3 attempts per 1 minute, 10 attempts per 15 minutes
- **Default lockout**: 1 hour, max 48 hours

Headers for rate-limited responses:

```
Retry-After: <seconds>
```

## API Prefix

All endpoints are prefixed with `public-api/v1/` internally but reflected from the root path.

## Examples

### List of all apps

```bash
curl https://YOUR_HOST/public-api/v1
```

Response:

```json
{
  "ok": true,
  "api": "public-api/v1",
  "auth": "Authorization: Bearer <token>, X-Device-Id: <hex>"
}
```

### Validate authentication token

```bash
curl -X POST https://YOUR_HOST/public-api/v1/auth/validate \
  -H "Authorization: Bearer abc123..." \
  -H "X-Device-Id: def456..."
```

Response:

```json
{
  "ok": true,
  "user": {
    "email": "user@example.com",
    "role": 1,
    "verified": 1
  }
}
```

### Get shell commands

```bash
curl -X GET https://YOUR_HOST/public-api/v1/shell/commands \
  -H "Authorization: Bearer abc123..." \
  -H "X-Device-Id: def456..."
```

Response:

```json
{
  "ok": true,
  "commands": {
    "start": "/menu_service_start",
    "stop": "/menu_service_stop",
    "restart": "/menu_service_restart",
    "status": "/menu_service_status",
    "help": "/menu_help",
    "logout": "/logout"
  }
}
```

### Restart a service

```bash
curl -X POST https://YOUR_HOST/public-api/v1/shell/restart \
  -H "Authorization: Bearer abc123..." \
  -H "X-Device-Id: def456..."
```

Response:

```json
{
  "ok": true,
  "message": "Service restarted successfully"
}
```

## CORS

CORS is handled automatically:

- Uses `APP_CORS_ORIGINS` environment variable (comma-separated)
- Autodetects current host if not specified
- Supports `*, https://your-domain.com` patterns

## HTTPS Only

Public API defaults to HTTPS-only unless `PUBLIC_API_REQUIRE_HTTPS` is set to `0`.
