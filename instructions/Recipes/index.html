How to use the recipe

To open a recipe, select any recipe card from the main view.

After opening a recipe, the user can review the ingredients, preparation steps, and other related information.

Creating new recipe

To create a new recipe, use the add button in the Recipes application.

Fill in all required fields and save the form.

Add new recipe form - click to enlarge.
  • Enter the recipe title.
  • Add the preparation description.
  • Attach ingredients and optional image.
  • Save the recipe.

Products management

The product management tools are used to maintain the list of ingredients.

This makes it easier to keep recipe data organized.

Product management interface.

Recipe with products you already have

This function helps the user find recipes based on available products.

This feature is useful for quickly deciding what can be prepared.

Sharing recipes

Recipes can be shared with other users through the sharing function.

Depending on the system configuration, sharing may include a direct link.

Share recipe interface.

📤 Sharing Recipe Photos

You can share recipe photos in two formats:

  • Image format (PNG, JPG) - Quick preview on any device
  • PDF format - Professional document format

Before sharing, select:

  • Recipe - Choose which recipe to share
  • Theme - Light or dark theme
  • Language - Choose the language

Continue to the last recipe

The continue function allows returning to the most recently opened recipe.

The application remembers the last active recipe.
