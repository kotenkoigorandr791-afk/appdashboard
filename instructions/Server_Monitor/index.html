Server Monitor Instructions

Server Monitor provides real-time monitoring of your server's resources, network activity, and installed modules.

Overview

Server Monitor displays comprehensive information about your server's current state, including network activity, disk usage, and loaded modules.

Server Resources - visual representation of CPU, memory, and overall server health.

Use this tool to monitor server performance, check available disk space, and verify that required Apache modules and PHP extensions are loaded.

Note: Data refreshes automatically. Green/purple indicators show active/loaded components, red indicates inactive/not loaded.

Network Interfaces

The Network Interfaces section displays real-time traffic for all network adapters on your server.

  • Download - Incoming data rate (bytes per second)
  • Upload - Outgoing data rate (bytes per second)
  • Total - Combined upload and download traffic
  • Speed - Current connection speed
Network Interfaces showing real-time traffic for each adapter.

Connected Drives

The Connected Drives section shows disk space usage for all drives mounted on your server.

  • Total Space - Total capacity of the drive
  • Free Space - Available space remaining
  • Usage Bar - Visual indicator (purple = used, green = free)
  • Percentage - Percentage of disk space used

Monitor disk usage to prevent storage issues. Consider cleaning up or expanding drives that exceed 80% capacity.

Apache Modules

The Apache Modules section lists all Apache web server modules and their current status.

Apache Modules - purple badges indicate loaded modules, red indicates not loaded.

Module status indicators:

  • Loaded - Module is active and available
  • Not Loaded - Module is not currently active

Use the search box to quickly find specific modules by name.

PHP Extensions

The PHP Extensions section displays all installed PHP extensions and their loading status.

PHP Extensions - all extensions shown with their current status.

Common PHP extensions include:

  • PDO - Database connectivity
  • cURL - HTTP requests
  • SimpleXML - XML parsing
  • Reflection - Code introspection

Most extensions should show Loaded for proper application functionality.
