Movie Manager Instructions

This page explains the main functions of the Movie Manager application.

Main view of the Movie Manager application with movie cards.

Main Page

The main page displays movie cards with essential information about each film. Each card shows:

  • Movie Title - The name of the film
  • Rating - User rating score
  • Genre - Category of the movie
  • Release Year - When the movie was released
  • Cover Image - Visual preview

This layout helps you quickly browse your movie collection.

Search & Filter

To find a specific movie, use the search box in the top-right corner. Type the movie title to filter results instantly.

Genre filter - select genres to narrow down your list.

You can also filter movies by genre using the genre filter button.

Watch Button

The Watch button is the main feature. Click it to start playing the movie.

Watch button - click to play the movie.

Note: Playback depends on whether the movie is local or external.

Local vs Non-Local Movies

Movies can be local (stored on your server) or non-local (from external sources).

Local movie - stored on your server.

Local movies open immediately without redirecting.

Non-local movie - opens on external page.

Non-local movies redirect to an external page for viewing.

Share Link

Important: Share Link is only available for non-local movies.

For non-local movies, share a link to the external page.

Share Link - copies URL to clipboard.

Click Share Link to copy the URL. Paste it anywhere.

Note: Non-local movies redirect to external pages. This is normal.

Comments

Leave comments to share your thoughts about movies.

Comments section.

The comments section allows you to:

  • Write your review
  • Read other comments
  • Discuss the movie
