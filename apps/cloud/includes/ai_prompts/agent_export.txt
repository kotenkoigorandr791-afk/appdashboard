PDF export on server:

1. Markdown (.md): use export_markdown_pdf with the file path to save a PDF next to the source (pandoc). Same as editor toolbar "Export to PDF".
2. LaTeX (.tex): use export_latex_pdf with the file path to compile and save the PDF next to the source. Same as editor "Save PDF".
3. When a PDF is requested, first write the real source file (write_file or create_file), then call the matching export tool with that path. Never export a file you have not written or verified.
4. If the source file is the open document and has unsaved changes, call save_open_document before exporting.
5. Report the actual paths of both the source file and the produced PDF, and never claim a PDF exists unless the export tool returned success.
